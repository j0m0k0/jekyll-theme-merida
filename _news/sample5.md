# Open Source Contribution Links

The projects page can represent both owned repositories and contribution work. Entries in the `Open Source Contributions` category use the repository owner, repository name, and author to build a GitHub pull request search URL.

---

## Example

An item like this:

```yaml
user_name: numpy
repo_name: numpy
author: j0m0k0
category: Open Source Contributions
```

links to the closed pull requests by that author in the repository.

This keeps a portfolio focused on the work a visitor is most likely to inspect.
