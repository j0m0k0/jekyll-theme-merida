# Merida Documentation

This directory contains documentation for Merida users and theme developers.

- [Installation](installation.md): clone `merida-starter`, install the gem, or work on the theme source.
- [Configuration](configuration.md): every site setting, collection, plugin, and data file shape.
- [Content Guide](content.md): author pages, posts, news, projects, and publications.
- [Customization](customization.md): override layouts, includes, CSS, images, favicons, scripts, and theme colors.
- [Search](search.md): Pagefind setup, indexing behavior, and deployment notes.
- [Deployment](deployment.md): build and deploy to GitHub Pages or a static host.
- [Troubleshooting](troubleshooting.md): common build and runtime problems.

Developer documentation:

- [Development](development.md): work on the theme locally.
- [Releasing](releasing.md): maintainer workflow for RubyGems and starter synchronization.

Start with [Installation](installation.md) if you are creating a new site, or [Development](development.md) if you are changing the theme itself.
