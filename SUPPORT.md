## Usage Questions

For usage questions, open a GitHub Discussion if discussions are enabled. Otherwise open an issue and label it as a question.

Include:

- What you are trying to do.
- What you expected to happen.
- What happened instead.
- Relevant `_config.yml`, front matter, or data snippets.
- Build or browser console errors.

## Bug Reports

Open a GitHub issue with:

- Merida version.
- Ruby, Bundler, Jekyll, Node.js, and npm versions.
- Operating system.
- Build command.
- Full error output.
- Minimal reproduction repository or file snippets.

## Feature Requests

Open a GitHub issue describing:

- The user problem.
- The behavior you want.
- Any alternatives you considered.
- Whether you can help implement it.

## Security Reports

Do not open public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
